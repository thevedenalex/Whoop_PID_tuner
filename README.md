# TinyWhoop PID Lab

**Онлайн: https://pidtune.veden.pro/** — работает прямо в браузере,
ничего не отправляет на сервер.

Веб-приложение-анализатор blackbox-логов (.bbl) и тюнер PID для гоночных тинивупов 65–75 мм
(Betaflight 4.4–4.5). Расчёт направлен на быстрые гонки: минимальная задержка фильтров,
максимальная резкость на стиках, стопы «по рельсам».

## Возможности

- **Собственный декодер Blackbox Data Version 2** — парсинг .bbl прямо в браузере,
  без сервера: I/P/S/G/H-фреймы, события, предикторы, развёртка переполнения time.
- **Выбор лога в файле** — авто-выбор самого информативного лога + ручное переключение.
- **Анализ полёта** — маска чистого полёта (исключение стоянки на столе, посадок,
  столкновений), перелёты, время установления, шум гироскопа, сатурация моторов,
  задержка отклика, оценка тюна 0–100.
- **Графики лога** — гироскоп, сетпоинт, моторы, газ, напряжение; исключённые
  участки подсвечены.
- **Чтение настроек из лога** — фактические PID/фильтры/TPA из H-заголовков,
  сравнение «сейчас в дроне → рекомендуем».
- **Рейты Actual по осям** — ввод гоночных рейтов (центр/макс/экспо), предзаполнение из лога.
- **Каталог компонентов** — рамы/моторы/пропы/FC/камеры/VTX с весами; влияние на тюн
  не только по весу (KV, число лопастей, шаг пропов, подшипники, тип гироскопа,
  жёсткость рамы с карбоновым усилителем).
- **Профили резкости** — «мягкий» / «гоночный» / «максимум», с оценкой задержки
  фильтров в миллисекундах относительно базы и лога.
- **CLI diff** — готовый блок команд для вставки в Betaflight Configurator.
- **Сохранение/загрузка сборки** в JSON.

## Что происходит под капотом

Подробный разбор конвейера — декодер .bbl, маска чистого полёта, метрики, все факторы,
влияющие на рекомендации (вес, KV, пропы, гироскоп, рейты, профиль, лог), оценка
задержки фильтров и осознанные упрощения: [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).

## Запуск

```bash
cd app
npm install
npm run dev
```

Сборка: `npm run build`. Проверки на реальных логах: `npm run test:logs`
(нужна папка testlogs рядом с app, в репозиторий не входит).

## Структура

```
app/
  src/lib/bbl/      — декодер .bbl + извлечение настроек из заголовков
  src/lib/analyze/  — метрики полёта и маска чистого полёта
  src/lib/tune/     — движок тюна (база, коррекции, профили, оценка задержки)
  src/components/   — UI-панели
  public/demo.bbl   — синтетический демо-лог (scripts/gen_demo.py)
```

`demo.bbl` сгенерирован синтетически, реальных полётных данных в репозитории нет.
